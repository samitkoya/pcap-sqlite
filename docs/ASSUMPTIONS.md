# Working assumptions

- **Product:** A four-day information security course demonstration for students and reviewers. It turns real DNS PCAPs into `dns_queries` and `domain_summary` SQLite tables, applies four fixed rule points, and shows evidence in a local dashboard. The two required root captures and their database paths stay intact.
- **Audience:** A presenter explaining the method during a viva, and classmates inspecting bundled or their own captures. A flag means review, not a malware verdict.
- **Stack:** Python 3, PyShark with TShark, pandas, scipy (brief requirement), SQLite, and standalone HTML/CSS/JavaScript served by `dashboard_server.py`. Implementations are in `pcap_sqlite/`; the root scripts preserve the course commands. There is no Node application build or framework to migrate.
- **Run/check commands:** `python dashboard_server.py`; `python -m unittest discover -s tests -v`; `python -m py_compile dns_feature_extractor.py detector.py dashboard_server.py`; `node --check web/assets/app.js`. The extractor commands are in the root `README.md`.
- **Stable boundaries:** No machine learning; preserve both SQLite tables, real PCAP provenance, the four scoring cutoffs, and Overview / Domain Detail tabs. Added indexes do not change table columns. The API adds fields and routes, while existing `GET /api/analysis?db=...` remains supported.
- **Uploads:** A user supplied capture is local evidence without a ground-truth label. Accept `.pcap`, `.pcapng`, and `.cap` up to 25 MiB, store it under ignored `data/uploads/`, and store its SQLite result under ignored `output/uploads/`. This size is a course-scale operational limit; larger captures can use the extraction CLI.
- **Local security model:** The dashboard binds to `127.0.0.1` and has no accounts or secrets. Host validation, same-origin browser behavior, file allowlisting, upload bounds, and a content security policy protect this local tool. It is not a public multi-user service.
- **Design:** Keep the approved two-tab information architecture and plain JavaScript so the code remains viva-friendly. Assets are served from `web/assets/`. No image asset is needed for this evidence-led UI.
- **Dependencies:** No application dependencies were added. TShark and temporary 7-Zip executables were downloaded from official distribution sites into ignored `.task1/` only to verify extraction in this checkout; a fresh clone must install TShark separately.
- **Claims:** Source-level normal or tool scenario labels do not certify individual domains. The selected captures cannot establish population-level precision, recall, or false-positive rate.
